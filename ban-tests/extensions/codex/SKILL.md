## Codex

Crie a pasta de artefatos de `ban-tests` pela regra do perfil. Use o CLI do checkout ativo para iniciar a sessao isolada:

```bash
pnpm --dir <repoRoot ativo> agents review test-reviewer <pasta da execucao>/r0 --repo <checkout revisado> < <briefing temporario>
```

Leia `review.md` quando o executor confirmar o isolamento.
